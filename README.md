## 💻 How to Preview & Run

### Method 1: Instant Browser Launch (Easiest)
Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local HTTP Server (Python)
If you prefer running via a local web server:
```powershell
# In PowerShell or terminal inside this folder:
python -m http.server 8000
```
Then visit: `http://localhost:8000`

## 🌐 Free 1-Click Deployment

### Option A: GitHub Pages
1. Push this folder to a GitHub repository (e.g. `khushisalian/portfolio`).
2. Go to repository **Settings** → **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` / `root` and click **Save**.
4. Your site will be live at `https://khushisalian.github.io/<repo-name>/`.

### Option B: Vercel or Netlify
- Drag and drop this folder directly into [app.netlify.com/drop](https://app.netlify.com/drop) or import from GitHub on [vercel.com](https://vercel.com).
- No build command required; publish directory is `./`.
